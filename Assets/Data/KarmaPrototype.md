# 염주 키워드 프로토타입

기존 씬의 `KnotAttack`에서 필요한 `ProjectileStorage`, `PlayerHealth`, `KarmaBeadHud`를 런타임에 연결한다. 씬이나 프리팹을 다시 구성할 필요는 없다. 이미지 에셋 없이 원형 염주와 텍스트로 표시한다.

## 조작과 저장

- **Shift 대시:** A/D 또는 방향키로 이동 중인 방향으로 빠르게 이동하며, 이동 입력이 없으면 마지막으로 바라본 방향으로 나간다. 왼쪽·오른쪽 Shift를 모두 지원한다. 속도 18, 지속 0.18초, 재사용 대기 0.8초이며 게임 시간 기준이다. 공중에서도 수직 속도를 유지하며 사용할 수 있고, 벽 충돌을 따른다. 누르고 있어도 자동 반복하지 않으며 드로잉·이동 공격·사망 중에는 사용할 수 없다. 선을 그리기 시작하면 진행 중 대시가 취소된다.
- **사망 후 재시작:** 화면 중앙의 `다시 시작 (R)` 버튼 또는 R키로 현재 전투 씬을 다시 불러온다. 살아 있을 때는 재시작되지 않으며 로딩 중 중복 입력을 막는다. 체력은 시작값 100, 적은 1명으로 돌아오며 염주·업력·탄환·방패·업장·대시 재사용 대기와 감속 상태가 초기화된다.
- **좌클릭 드래그:** 플레이어 위치에서 시작하는 이동·공격 경로를 그린다. 놓으면 플레이어가 경로를 따라 이동하며 적을 타격한다. 전체 경로가 0.75유닛 이상이고, 실제 시작 위치에서 0.4유닛 이상 움직인 뒤에만 피해를 줄 수 있다. 제자리 클릭이나 아주 짧은 선은 공격·능력 소모를 하지 않는다.
- **우클릭 드래그:** 탄막 감속·카르마 획득용 실을 그린다. 놓을 때 닫힌 고리가 있으면 가까운 탄환의 카르마를 얻는다. 공격이나 자동 이동은 하지 않는다.
- 닫히지 않은 우클릭 선은 마우스를 놓아도 **실제 시간 5초간 방패**로 남는다. 닿는 탄환을 계속 감속하며 마지막 1초에 서서히 사라진다. 최근 방패 최대 3개를 유지하고, 새 드로잉이나 공격은 기존 방패를 지우지 않는다. 플레이어가 멀어져도 선의 위치에서 감속은 유지되지만 사거리 밖에서는 업력을 얻을 수 없다. 방패 자체는 세계 감속·회색 화면을 유지하지 않으며, 드로잉 비활성화나 사망 시 정리된다.
- **선을 그리는 동안 화면이 회색으로 바뀌고, 좌클릭은 8%, 우클릭은 3% 속도로 세계가 느려진다.** 적의 발사 시간과 탄환의 실제 이동도 함께 느려지며, 놓거나 드로잉이 취소되면 원래 속도로 복구된다. 능력 꺼내기나 폭주 경고가 겹치면 남아 있는 효과를 보존한다. 메인 카메라의 화면 효과를 자동 연결한다.
- 우클릭 실과 카르마 획득은 플레이어 반경 **화면 가로폭의 65%(최소 12유닛)** 안에서 동작하며 카메라 확대·축소와 화면 비율에 맞춰 함께 조절된다. 실에 닿은 탄환은 추가로 25% 속도로 느려지지만 최소 속도 0.2로 계속 움직이며 사라지지 않는다. 선에서 벗어난 뒤 0.4초가 지나면 속도가 복구된다.
- 가까운 탄환을 처음 감속하면 **업력(잉크) 1**을 얻는다. 탄환 한 발당 평생 한 번만 획득할 수 있다. 위쪽 노란 막대가 업력이며 상한은 100이다.
- 도형 안의 포획 가능한 탄환은 **기본 업력 소모 없이 한 번에 카르마로 저장**한다. 업력이 0이어도 도형 포획은 중간에 끊기지 않는다. 큰 고리 뒤에 작은 고리나 꼬리가 붙어도 모든 닫힌 영역을 판정하며, 8자 도형의 양쪽 영역과 경계 위 탄환도 포함한다. 탄환은 계속 날아오고 피해 판정도 유지된다. 이미 카르마를 얻은 탄환과 사거리 밖 탄환은 제외한다. 저장 가능한 염주가 없으면 해당 탄환은 포획되지 않는다. 비용을 다시 적용하려면 `ProjectileStorage.energyPerKarma`를 조절할 수 있으며 기본값은 0이다.
- 도형으로 카르마를 얻은 탄환은 몸체 전체와 테두리를 회색으로 표시한다. 빨간 고리의 획득 불가 특수 탄환은 적 발사 패턴에서 제거했다. 일반 탄환의 수명과 플레이어 접촉 규칙은 유지된다.
- 같은 키워드를 다시 포획하면 기존의 정상 염주에 합쳐지며, 염주 하나당 계수는 최대 8이다. 넘치는 탄환은 다음 빈 염주에 이어서 저장하므로 기존 염주가 가득 차도 빈 슬롯이 있으면 여러 발 모두 저장된다. 부패 시간도 실제 시간 5초로 갱신된다. 부패한 염주는 합치거나 되살리지 않는다. 서로 다른 키워드는 별도 슬롯을 사용한다.
- 슬롯은 8개이며, 정상 염주를 마우스로 끌어 필드에 놓으면 **다음 공격에 장전**된다. 숫자키로 능력을 선택하는 기능은 제거했다.
- 필드에 놓으면 염주 슬롯이 비워지고 해당 위치에 속성 표식이 나타난다. **공격을 준비하는 동안 해당 속성 색으로 화면이 물들고 최대 실제 시간 3초간 게임이 20% 속도로 느려진다.** 그 안에 사용하지 않으면 능력이 사라진다. 유효한 이동 공격 경로를 확정하면 준비 감속을 즉시 해제하고, 실제 이동 후 능력이 소모되면 색상 효과와 대기 시간도 즉시 끝난다. 드로잉·히트스톱이 겹쳐도 이미 끝난 카르마 감속을 다시 적용하지 않는다.
- 장전된 속성은 다음 유효한 경로 공격에서 **시작 위치로부터 실제로 0.4유닛 이동한 시점에** 한 번 소모되어 그 경로에서 맞힌 모든 적에게 적용된다. 이동하기 전에 취소하면 능력이 남는다. 포획이나 유효하지 않은 경로도 장전을 소모하지 않는다.
- 한 번에 하나의 능력을 장전한다. 이미 장전되어 있으면 다른 염주를 덮어쓰거나 소모하지 않는다. HUD 위나 게임 화면 밖에 놓으면 취소된다. 빈 염주와 부패한 염주는 장전할 수 없다.
- 장전 없이 공격하면 일반 공격을 한다. 염주의 능력을 자동으로 꺼내 쓰지 않는다. 염주를 드래그 중에는 실을 그리거나 공격을 시작하지 않는다.
- 빈 슬롯이 없어도 합칠 수 있는 정상 염주가 있으면 강화한다. 합칠 염주와 빈 슬롯이 모두 없으면 해당 탄환은 포획하지 않는다.
- 화면에는 능력 이름만 글자로 남긴다. 체력은 숫자 없는 막대, 염주의 부패 진행은 고유 색이 서서히 검은색으로 변하는 모습으로 표시한다. 슬롯 번호·계수·초 단위 카운트다운·조작 안내·사망 안내 문구는 표시하지 않는다.
- 적은 **3초마다 탄환 1발만 발사**한다. 발사마다 독 → 저주 → 빛 → 어둠으로 순환하며, 새로 발사한 탄환은 모두 카르마를 얻을 수 있다. 흡수 불가 특수 탄환을 만드는 분기를 제거했다. 발사 간격은 `throwInterval × intervalMultiplier`로 조절하며 `cycleKeywords`를 끄면 프리팹의 `keyword`를 사용한다.
- 속성을 실은 경로 이동 중에는 해당 속성의 잔상과 입자가 플레이어를 따라 나온다. 독은 녹색 입자, 저주는 퍼지는 보라색 입자, 빛은 위로 뜨는 금색 입자, 어둠은 푸른 잔상을 사용한다. 정지 상태나 공격 종료 후에는 새 입자를 방출하지 않는다.

## 능력

| 종류 | 동작 |
| --- | --- |
| 독 | 명중 시 실제 가한 피해의 5% × 염주 계수를 5초간 고정 지속 피해로 적용. 여러 독은 독립적으로 적용되며 저주로 재증폭되지 않는다. |
| 저주 | 염주 계수만큼 중첩, 최대 30. 제거 전까지 유지. **임시 효과:** 스택마다 일반 피해를 1% 더 받는다. `ClearCurse()`로 제거할 수 있다. |
| 빛/어둠 | 각각 6초간 유지. 같은 효과는 시간을 갱신하고, 반대 효과는 기존 효과를 제거한 뒤 적용한다. |
| 빛 제거 | 시간 만료·반대 효과·대상 사망 시 소유 플레이어의 잃은 체력 5% × 염주 계수 회복. |
| 어둠 제거 | 대상의 가하는 피해 10% 감소 중첩을 1개 추가(최대 3)하고, 부여 당시 피해의 20% × 염주 계수 추가 피해. 약화는 대상 사망까지 유지되며 이후 발사하는 탄환에 적용된다. |

저주의 구체적 효과, 빛 회복량, 어둠 약화량/추가 피해량은 기획에 수치가 없어 임시값이다. `Enemy`의 Keyword tuning에서 조절할 수 있다. 빛과 어둠은 하나의 상호 전환 계열이지만 저장 슬롯과 탄환 속성은 구분한다.

## 부패와 업장 폭주

- 저장 후 **실제 시간 5초**가 지나면 부패한다. 기존 게임 시간 20초보다 빠르게 진행되며, 드로잉 슬로모션으로 시간을 늘릴 수 없다. 완전 일시정지와 히트스톱 중에는 부패가 잠시 멈춘다.
- 부패 염주는 사용할 수 없고 계속 슬롯을 차지한다. 개별 폐기는 제공하지 않는다. 부패 직전에는 붉게 점멸한다.
- 부패 염주가 3개 이상이면 **실제 시간 2초간 붉은 점멸과 35% 슬로모션**으로 경고한다. 이때만 부패한 염주도 꺼낼 수 있으며, 시간 안에 이동 공격으로 실제로 움직여 사용하면 해당 슬롯이 비워진다. 꺼내기만 하거나 움직이기 전에 취소해 버티는 것으로는 폭주를 막을 수 없다.
- 경고가 끝나도 3개 이상 남아 있으면 부패 슬롯을 모두 비우고, 플레이어 위 2유닛 위치에 업장 덩어리를 만든다. 정상 염주는 유지된다.
- 업장은 0.6초간 발사 전 점멸한 뒤 속도 2로 플레이어를 추적한다. 접촉하거나 비행 3초가 지나면 **반경 3.5유닛**에서 폭발하며, 범위 안 플레이어에게 **34 피해를 한 번** 준다. 부패 수와 관계없이 한 번의 기본 피격으로 취급한다. 기존 반경 1.25 대비 반경은 2.8배, 면적은 약 7.8배다. 추적 중에도 실제 피해 반경과 같은 경고 원을 표시한다. 실로 감속·포획할 수 없으며 범위 밖으로 이동하면 폭발을 피할 수 있다.
- 폭발 시 **충격파 3겹·피해 범위 테두리·중심 섬광·불꽃 96개·보라색 연무 40개·화면 흔들림**을 표시한다. 전용 `KarmaExplosionEffect`가 약 0.95초의 실제 시간 동안 재생되므로 감속 중에도 오래 남지 않으며, 업장 본체가 사라지거나 플레이어가 폭발로 사망해도 끝까지 재생된다. 종료나 씬 재시작 시 생성한 입자·재질·텍스처를 정리한다.
- `ProjectileStorage`의 `decaySeconds`, `outbreakThreshold`, `outbreakSpeed`, `outbreakDamage`, `outbreakLifetime`에서 조절한다. 기존 씬에서는 Play 중 플레이어 Inspector에서 확인할 수 있다.
- 플레이어는 시작·최대 체력 모두 **100**이며, 일반 탄환 기본 피해는 **34**다. 회복이나 피해 감소가 없으면 **100 → 66 → 32 → 0**으로 세 번 피격 시 사망한다. 업장 폭발 기본 피해도 34다. 사망 시 이동·대시·드로잉을 막고 사용 중이던 능력과 슬로모션을 해제하며 재시작 버튼을 표시한다. R키나 버튼으로 재시작하면 현재 씬의 시작 상태로 돌아간다.
- 능력 꺼내기·폭주 경고·히트스톱은 `GameTimeEffects`가 함께 관리한다. 더 느린 효과가 우선하며, 하나가 끝나도 나머지 효과의 시간 설정을 보존한다.

## Play 확인 순서

1. 기존 전투 씬을 Play하여 적 1명, 하단 염주 8개, 체력·업력 막대가 표시되는지 확인한다. 좌클릭 선으로 이동하며 적을 공격하고, 제자리 클릭으로는 공격할 수 없는지 확인한다.
2. 우클릭 선으로 가까운 탄환을 느리게 해 업력을 얻고, 고리로 묶어 카르마를 얻는다. 열린 선은 놓아도 5초간 방패로 남고, 닫힌 고리는 방패를 만들지 않는지 확인한다. 두 경우 모두 탄환이 사라지지 않고 계속 위험한지 확인한다. 같은 속성은 기존 염주에 합쳐지고, 같은 탄환은 자원을 반복 지급하지 않는다.
3. 정상 염주를 필드로 드래그해 놓고 슬롯이 비워지는지, 사용하지 않으면 색상 효과·슬로모션·능력이 3초 후 사라지는지 확인한다. 그 전에 다음 실 공격을 확정하면 속도가 즉시 복구되고, 실제 이동 후 속성이 한 번 적용되며 색상 효과가 끝나는지 확인한다. 숫자키로는 아무 능력도 선택되지 않는다.
4. 저주를 여러 번 부여해 최대 30 중첩, 독의 지속 피해, 빛/어둠 교체 및 6초 만료를 확인한다. 플레이어가 피해를 받은 뒤 빛 해제로 회복하는지 확인한다.
5. 염주 하나를 방치하면 감속 중에도 실제 5초 후 완전히 검게 변하며 사용할 수 없는지 확인한다. 부패 2개까지는 슬롯에 남는지 확인한다.
6. 부패가 3개 되면 먼저 경고가 나오고, 시간 안에 꺼낸 능력으로 공격해야 폭주를 피할 수 있는지 확인한다. 경고를 무시하면 업장이 발사·추적·폭발하며 34 피해를 주는지, 실로 감싸도 흡수되지 않는지 확인한다.
7. 슬롯을 모두 채운 상태에서 추가 포획을 시도하여 넘친 탄환이 사라지지 않는지 확인한다.
8. 좌우 이동과 Shift로 대시 방향·재사용 대기·벽 충돌을 확인한다. 사망 후 R키 또는 화면의 재시작 버튼을 사용하고, 체력 100·적 1명·빈 염주·기본 속도로 돌아오는지와 대시·선 그리기가 다시 가능한지 확인한다.

## 적 재생성

기존 씬의 적이 시작될 때 `EnemyRespawner`를 자동으로 만들어 **적 1명**을 유지한다. 처치하면 0.75초 뒤 원래 위치에 다음 적이 재생성된다. 체력·상태이상은 초기화되고 탄환 프리팹·플레이어 타깃은 유지된다. 플레이어 사망 시 재생성을 멈춘다. `simultaneousEnemies`, `enemySpacing`, `respawnDelay`로 인원·간격·부활 시간을 조절할 수 있다.

## 끝없이 이어지는 바닥

플레이어에 자동으로 연결되는 `EndlessGround`가 기존 `Floor`의 높이·렌더러·충돌체를 사용해 바닥 7개를 재사용한다. 플레이어가 좌우로 이동하면 화면 밖 구간만 반대쪽으로 재배치해, 계속 이동해도 서 있을 땅이 끊기지 않는다. 바닥 높이는 동일하게 유지되며 생성 오브젝트 수는 늘어나지 않는다.

## 자동 검증 기록

Unity 6000.3.4f1에서 실제 Main 씬을 Play하여 **352/352 검사 통과**. 별도 프로젝트 사본에서 검증했다. 12회 연속 공격에서 12발의 포획 가능한 단발 탄환만 생성, 탄환 프리팹에 저장된 실제 피해 34, 일반 탄환 세 번의 실제 충돌과 업장 세 번의 폭발에서 100 → 66 → 32 → 0으로 세 번째 피격 사망, 최대 체력 100, 감속 중에도 실제 5초 부패와 일시정지 중 부패 정지를 확인했다. 원본 탄환 프리팹의 피해 설정도 Unity Prefab API로 저장했다.

업장 폭발 반경 3.5, 경고 원과 실제 피해 범위 일치, 기존 반경 밖의 대상에게 피해 적용, 범위 밖 회피, 중복 피해 차단, 충격파 3겹·범위 테두리·130개 이상 입자, 강한 감속 중 수명 종료, 사망 후 이펙트 유지와 정리 및 실제 렌더링 화면도 확인했다. 업장 추적과 폭발 피해는 플레이어의 실제 Rigidbody 위치를 기준으로 판정한다.

업력 0에서 서로 다른 속성 8발 동시 포획, 실제 우클릭 드래그로 9발 포획, 기존 7단계 염주에 12발 추가 시 8·8·3으로 분산 저장, 큰 고리와 작은 고리·꼬리가 연결된 도형, 8자 양쪽 영역, 경계·모서리 포획, 도형 밖·흡수 불가·중복 보상 제외, 포획 탄환 전체 회색 표시를 확인했다. 적 1명 유지·5회 재생성과 재시작 후 인원도 통과했다.

왼쪽·오른쪽 Shift 입력, 실제 약 3유닛 대시, 수직 속도 보존, 재사용 대기·길게 누르기 반복 차단, 벽 충돌, 선 그리기·이동 잠금·사망 중 대시 차단도 확인했다. R키와 재시작 버튼이 사용하는 동작으로 실제 씬을 두 번 연속 다시 불러왔으며, 살아 있을 때 재시작 차단, 중복 로딩 차단, 체력·염주·업력·탄환·방패·업장·적 1명·바닥·대시 상태 복구, 남아 있던 감속·히트스톱 해제, 재시작 후 실제 대시 이동까지 통과했다.
